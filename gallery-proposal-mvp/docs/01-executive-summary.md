# Executive Summary: What You're Building

## The Product
A split-screen web app where gallery staff chat with an AI assistant (Claude) to create artwork proposals. As you chat, the right side of the screen updates in real-time showing artworks and proposal previews. Say "export" and get a professional PDF.

## The Demo (5 minutes)
1. Open app → AI greets you, shows 8 artworks
2. Click 2-3 artworks OR type "add the Frankenthaler"
3. Watch preview build on the right side
4. Type "export" → Download PDF proposal

## What Makes This Special
- **Natural conversation** replaces complex forms
- **Live visual feedback** (see what you're building)
- **Professional output** (clean PDF ready to send)
- **Zero learning curve** (if you can text, you can use this)

## Tech Stack
- React + Tailwind + Claude API + jsPDF
- Desktop only
- No database (session memory)
