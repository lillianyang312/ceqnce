# PDF Output Specification (Complete)

## PDF Structure Overview

The PDF should contain **9-11 pages** depending on the number of artworks selected:

1. **Cover Page** (1 page)
2. **Introduction & Context** (1 page)
3. **Proposal Summary Snapshot** (1 page)
4. **Artwork Pages** (1 page per artwork = 3 pages for 3 artworks)
5. **Terms & Conditions** (1 page)
6. **Contact & Thank You** (1 page)

Total for 3 artworks: **9 pages**
